## Default Permission

Sharing text or a picture, reading aloud with the phone's voices, saving or opening a file the reader chooses, choosing a folder to keep in step through, opening a web page in the browser, and handing a downloaded update to Android's installer.

#### This default permission set includes the following:

- `allow-share`
- `allow-speak`
- `allow-stop-speaking`
- `allow-save-text`
- `allow-open-text`
- `allow-open-file`
- `allow-pick-folder`
- `allow-battery-settings`
- `allow-open-link`
- `allow-voices`
- `allow-share-image`
- `allow-save-image`
- `allow-install-update`
- `allow-list-computer-pictures`
- `allow-read-computer-picture`
- `allow-save-computer-picture`
- `allow-share-computer-pictures`
- `allow-open-computer-file`
- `allow-schedule-notifications`
- `allow-cancel-notifications`
- `allow-notify-now`
- `allow-set-widget-data`
- `allow-pin-widget`
- `allow-take-launch`
- `allow-listen-start`
- `allow-listen-control`
- `allow-listen-status`
- `allow-save-to-gallery`
- `allow-share-images`
- `allow-share-file`
- `allow-save-backup-copy`
- `allow-list-backup-copies`
- `allow-read-backup-copy`
