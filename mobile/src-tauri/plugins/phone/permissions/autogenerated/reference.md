## Default Permission

Sharing text, reading aloud with the phone's voice, and saving or opening a file the reader chooses.

#### This default permission set includes the following:

- `allow-share`
- `allow-speak`
- `allow-stop-speaking`
- `allow-save-text`
- `allow-open-text`
