## 4. Things learned today (so they aren't relearned)

- **Tauri versions:** the npm `@tauri-apps/*` packages must match the Rust crates' major.minor, or `tauri build` stops. Installing `@tauri-apps/plugin-dialog@latest` pulled `@tauri-apps/api` up to 2.12. They are now pinned: `plugin-dialog ~2.7.0`, `api` locked at 2.11.1.
- **A second window (the slide screen)** must be created from Rust with the main window's `additionalBrowserArgs`, or WebView2 hangs (`show_window_open`).
- **The emulator:**
  - An x86_64 APK won't install on a phone, which says "not compatible". For the owner's phone, always build `android.ps1 -Release` (arm64 + armv7, release key); it then installs as an update.
  - The emulator ran out of space; reinstalling there needs `pm uninstall` first.
  - Through the emulator's network, the phone couldn't read the computer's answer; the real phone was fine.
- **The owner's phone:**
  - USB debugging is on (Developer options) and this PC is authorised.
  - A release build has no WebView devtools, and `uiautomator dump` of the WebView goes stale. Use `adb exec-out screencap -p` with taps by coordinate (the screen is 1200×2652).
- **Git:** `git config --global --add safe.directory "%(prefix)///Private/Other/Code/bible"` was needed (the share's ownership). It's done on this PC; the other PC may need it too.
- **PowerPoint check:** the video extension uri is `{DAA4B4D4-6D71-4841-9C94-3DE7FCFB9230}`. PowerPoint COM (`Presentations.Open`, `MediaFormat.IsEmbedded`) checks it without a window. Only do this when PowerPoint isn't already open.
