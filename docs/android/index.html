How to install it
  1. Tap Download for Android above, on the phone. If the browser warns that the file might be harmful, choose Download anyway; it says this about every app that does not come from the Play Store.
  2. When the download finishes, tap Open, or find BibleConcordance_Android_0.2.1.apk in the phone's Files app under Downloads and tap it.
  3. The first time, Android says that the browser (or the Files app) is not allowed to install apps. Tap Settings, switch on Allow from this source, and go back.
  4. Tap Install. If Google Play Protect says it does not recognise the developer, choose Install anyway (sometimes under "More details"). The app is not listed on the Play Store, so Google has no record of it.
  5. Tap Open. The first start takes a few seconds while the Bible is unpacked; after that it opens at once, where you left off.
Updating, and moving your notes
  • The phone app does not update itself. When a newer version is listed here, download and install it the same way. It installs over the old one and keeps your bookmarks, highlights and notes.
  • Save a backup first (in the app: More → Save a backup) if your notes matter to you. Uninstalling the app deletes them.
  • The same backup file can be restored in the Windows app (My Study → Import backup), and a backup made there can be restored on the phone (More → Restore a backup). There is no automatic syncing.

What's inside

One search box

Type a reference such as "John 3:16" or "1 cor 13" to go straight there. Type a word, a phrase or a subject, such as "gifts of the Spirit", to search the whole Bible, one testament or one book.

Five translations

BSB, KJV, ASV, WEB and YLT, with the words of Jesus in red. Swipe sideways to turn the chapter.

Tap a verse

Bookmark it, highlight it in five colours, write a note on it, see its cross-references, compare it across the translations, share it or copy it.

Read aloud

With the phone's own voice, from any verse, carrying on into the next chapter.

Bible dictionary

Easton's and Smith's, with every Scripture reference in an article a link.

Topics and reading plans

Topics from Nave's and Torrey's topical Bibles, four reading plans, and a verse for the day.

Backup

Save your bookmarks, highlights, notes and reading plans to a file, and restore it on the phone or in the Windows app.

Light and dark

Choose the text size and a light or dark theme. No account, no adverts, no internet needed.

What it leaves out

The commentaries, Strong's word study, the Hebrew and Greek texts, the map, the people and places index, the sermon builder, the Library and the pictures are in the Windows app only. They are what make that download large.

It is for Android phones. There is no iPhone version.
