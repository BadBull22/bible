## 2. What's in 2.4.2 (since 2.4.1)

**Getting started window** (`src/components/WelcomeWindow.tsx`). It explains where the
optional extras live, since they are spread over different menus, with live status for each
and a way straight there:

- Natural reading voice: download in place (reuses `VoiceDownload`).
- Library: "Show me" opens Study ▸ Library ▸ Get more.
- Bible pictures: opens Explore ▸ Pictures ▸ Download.
- NIV / NKJV / ESV keys: opens Settings scrolled to Online translations
  (`SidePanel` `{ kind: "settings", focus: "online" }`).

When it opens by itself (logic in `App.tsx`, after the launch video), using localStorage:

- Always on the first run.
- On later starts only while the natural voice isn't installed.
- **At most 3 automatic openings in total** (`welcome:count`, `WELCOME_MAX_AUTO`).
- Never again once "Don't show this again" is ticked (`welcome:off`).
- Settings ▸ "Getting started … Click here ›" opens it any time. The "Click here ›" hint was
  added because the button looked like plain text.

**Downloaded books in the book list and the reading area.**

- The left-hand book list has a new **Books** section under Apocrypha. It lists installed
  Library books and devotionals (devotionals tagged "daily"), plus a **Get more books ›**
  link. That link opens Library ▸ Get more with the kind filter set to Books
  (`SidePanel` `library.only`, `LibraryPanel` `onlyKind`).
- Choosing a book, from the sidebar or "Read" in the Library, now opens it **in the main
  reading pane** where the Bible text normally is, not in a side panel.
  - `BookPanel` has `layout="main"`; the side-panel layout still exists but nothing uses it.
  - App state `readingBook` decides what the pane shows.
  - Any Bible navigation (sidebar book/chapter, search jump, Back, Home) clears it, and so
    does "Back to the Bible".
  - The ←/→ chapter shortcuts are off while a book is open.
  - The list refreshes on the existing `library-changed` event, so it updates on install or
    remove.
  - The old `{ kind: "book" }` side panel was removed.

Not changed: Bibles still go to the translation list, commentaries to the Commentary panel,
dictionaries to the Dictionary panel. Apocryphal books inside a *downloaded* Bible are still
skipped on install, because `library/refs.rs` maps only the 66 books. The sidebar's
Apocrypha section is the built-in text only. Changing that was offered; the user didn't ask
for it.

Library downloads come from the CrossWire Bible Society (`crosswire.org/ftpmirror/...`,
`src-tauri/src/library/mod.rs`).
