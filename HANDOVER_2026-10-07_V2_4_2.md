## 2. What's in 2.4.2 (since 2.4.1)

Explains where the optional extras live, with live status for each and a way straight there:

- Opens by itself on the first run, and on later starts only while the natural voice isn't

### Downloaded books in the book list and the reading area

  plus "Get more books ›").
- A book opens in the main reading pane (`BookPanel layout="main"`, App state

### Library: more sources (`library/mod.rs` `SOURCES`)

"Get more" has a **From** selector. All sources are HTTPS and use the same SWORD format:

| id | Source | Catalogue / zips |
|---|---|---|
| `crosswire` | CrossWire main | `…/sword/raw/mods.d.tar.gz`, `…/packages/rawzip/` |
| `ebible` | eBible.org (1,530 Bibles) | `ebible.org/sword/mods.d.tar.gz`, `/sword/zip/` |
| `attic` | CrossWire Attic (88) | `…/atticraw/`, `…/atticpackages/rawzip/` |
| `wycliffe` | Wycliffe (44) | `…/wyclifferaw/`, `…/wycliffepackages/rawzip/` |
| `netbible` | NET Bible free edition (bible.org) | `…/pub/bible.org/sword/`, `…/packages/` |
| `beta` | CrossWire Beta (11) | `…/betaraw/`, `…/betapackages/rawzip/` |

- The list follows CrossWire's `masterRepoList.conf`. Left out on purpose: Xiphos (plain
  HTTP only), IBT and STEPBible (FTP only), Lockman and Deutsche Bibelgesellschaft (locked,
  paid modules).
- Catalogues are cached per source (`mods.d.tar.gz` for CrossWire, `mods.d.<id>.tar.gz` for
  the rest). `modules.source` records where each installed item came from.
- The **Afrikaanse Bybel (Afr1953)** is pinned at the top of the CrossWire list whatever the
  language filter (`PINNED` in `LibraryPanel.tsx`). It can't be bundled: its licence is
  "Copyrighted; Permission to distribute granted to CrossWire". Bundling would need the
  Bybelgenootskap van Suid-Afrika's permission.

### Library: Add from file (`import_check` / `import_install`)

A third Library tab. The reader picks a file; the app checks it and shows a report; nothing
is installed until they press Add. Items are marked "Added by you" (`modules.source = 'file'`).

- **The stance (user's explicit wish):** only legitimate files. The app never removes copy
  protection; protected files are refused with a plain message, and the screen reminds
  people to add only files they have the right to use.
- **How it's strict:** the file is unpacked into a holding folder
  (`library\tmp\_import`) and run through the whole conversion inside a database
  transaction that is rolled back (`commit: false`). Only the second, explicit step commits.
- **SWORD module zip** (`unzip(strict)`): exactly one module, nothing else in the zip, size
  limits, readable driver/versification, not locked, not a copy of something built in, text
  must decode, a Bible needs at least 20 verses.
- **EPUB** (`library/epub.rs`, uses `roxmltree`): reading order from the OPF spine, chapter
  titles from the nav document or `toc.ncx`, else the page's first heading. Pages without a
  title join the chapter before. Only text is kept (scripts, styles and images dropped).
  Refused: DRM (`META-INF/encryption.xml` with anything other than font obfuscation, or
  `rights.xml`), books with almost no text (scans).
- **PDF** (`library/pdf.rs`, uses `pdf-extract`/`lopdf`): text per page, lines rejoined into
  paragraphs, hyphenated words rejoined, page numbers and running headers dropped. Chapters
  from bookmarks (two levels), else divided into parts. Refused: encrypted PDFs, scans with
  no text, text that doesn't decode. Parsing runs inside `catch_unwind`.
- **Shared:** Bible references in the prose become links (`epub::link_references`,
  chapter:verse forms only). Sections over 60,000 characters are split into ~25,000-character
  parts (`split_long`). A missing or junk title falls back to the file name, which the page
  sends in an `x-file-name` header alongside the raw file bytes.
- **Not built (user decided to leave out):** USFM/OSIS/Zefania Bible files, Kindle files,
  OCR for scanned books, an Afrikaans dictionary (the free ones cover too little Bible
  vocabulary: 3 of 19 test words).
- Probe files for the ignored tests are in
  `%LOCALAPPDATA%\bible-concordance-build\library-probe\{other,epub,pdf}`:
  `cargo test import_real -- --ignored`, `real_epubs`, `real_pdfs`.

### Book reader: finding your place, and listening (`BookPanel.tsx`)

- **Slider** across the whole book, by text length (`TocEntry.chars`), sticky at the top. It
  shows the percentage and, while dragged, the section it would land in.
- **Remembered place:** section plus how far down it (`localStorage` `book:place`), so a book
  reopens where the reader stopped.
- **PDF page numbers:** page starts are stored in the text as `⟪47⟫` markers
  (`epub::page_mark`), drawn by `RichText.tsx` as small grey numbers and stripped by
  `plainText` (so they aren't read aloud or copied). `modules.features = "pages=N"`;
  `library_book_page` finds the section for a page. PDFs added before this have no markers
  and must be added again.
- **Listen from here** reads from the paragraph at the top of the window and carries on into
  the next section (`LISTEN_FINISHED_EVENT`, sent by `App.tsx` when a "selection" reading
  ends by itself).

### Clickable words in untagged Bibles (`ChapterView.tsx` `plainWords`)

Library Bibles (and every extra column in side by side) have no Strong's tagging, so a word
can't be looked up directly. Each word now opens the Interlinear panel for its verse. 39
CrossWire Bibles do carry Strong's tags, which the installer currently drops; keeping them
was offered and not asked for.
